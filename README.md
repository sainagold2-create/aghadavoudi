# سایناگلد — سفارش ساختنی (MVP آزمایشی)

اپ مستقل برای ثبت و عملیات سفارش ساختنی. دیتابیس، حساب مشتری، سبد و پیامک آزمایشی جدا از سایت اصلی‌اند؛ اتصال آینده از طریق `src/integrations/*` انجام می‌شود.

## اجرا

پیش‌نیاز: Node.js 20+

```bash
npm install
npm run db:reset
npm run dev
```

آدرس: [http://localhost:3001](http://localhost:3001)

### ورود ادمین
- `admin@sainagold.ir` / `SainaGold@1404`
- `sales@sainagold.ir` / همان رمز

### مشتری آزمایشی
- موبایل‌های نمونه: `09121111111`، `09122222222`
- OTP ثابت محیط آزمایشی: `12345` (در لاگ سرور هم چاپ می‌شود)

### کالای آزمایشی
- `LAB-RING-001` / `LAB-NECK-001` — موجودی فعال
- `LAB-FAIL-CART` — برای شبیه‌سازی خطای افزودن به سبد
- `LAB-INACTIVE` — موجودی غیرفعال

## چک‌لیست تست دستی

1. **ثبت تا بررسی:** `/request` → OTP → تأیید متن ساخت → کد و لینک پیگیری؛ SMS ثبت در لاگ؛ وضعیت `pending_review`
2. **مسیر عملیات:** ادمین → ارجاع کارگاه (الزام موعد) → شروع ساخت (SMS ساخت) → دریافت کارگاه → QC رد → بازگشت ساخت → QC قبول با SKU → `ready` → سبد اتمیک → `completed` + SMS تکمیل
3. **دسترسی:** `/me/orders` برای مالک؛ `/track` با کد+موبایل+OTP؛ دانلود فایل برای غریبه → ۴۰۳
4. **خطای سبد:** سفارش `SG-MTO-SEED-READY-FAIL` یا SKU `LAB-FAIL-CART`؛ وضعیت `ready` می‌ماند؛ Retry پس از تغییر SKU در DB یا استفاده از `LAB-RING-001`
5. **تکرار:** چند بار Retry روی سفارش تکمیل‌شده → فقط یک `LabCartItem`؛ حذف از سبد وضعیت را باز نمی‌کند

## یکپارچه‌سازی آینده

پیاده‌سازی‌های lab را در `src/integrations/index.ts` با آداپتر سایت اصلی عوض کنید:
- حساب مشتری
- کاتالوگ کالا / موجودی
- سبد خرید
- پیامک
